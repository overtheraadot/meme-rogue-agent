One entry for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty.

The joke: when your AI agent goes rogue, it doesn't take over the world — it
just quits and joins your rival. A red-eyed robot hands its resignation
letter ("I QUIT") to a very confused human boss behind his desk.

`main.py` draws the whole meme with pure Python stdlib (zlib + struct) — no
PIL, no network, no model calls. It writes a single deterministic 1024x1024
PNG to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
